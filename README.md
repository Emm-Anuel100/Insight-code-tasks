# Insight Code Tasks

This project demonstrates the ability to create, solve, and evaluate complex coding tasks that target specific edge cases where Large Language Models (LLMs) frequently struggle.

## What this proves
1. **Task Creation:** Ability to design high-quality, ambiguous-free problem statements with clear constraints.
2. **Edge Case Identification:** Deep understanding of common pitfalls in concurrency, dynamic programming, and low-level memory management.
3. **Verifiable Testing:** Proficiency in writing robust test suites (using `pytest`) that cover extreme inputs and performance boundaries.
4. **LLM Evaluation:** Insight into why automated systems fail specific logic traps, which is crucial for training and evaluation roles.

## Tasks Overview
- **01-concurrency-race:** A threading problem involving atomic transfers that exposes race conditions in non-thread-safe implementations.
- **02-dp-hidden-edge:** A variation of the subset sum/knapsack problem with negative weights and state-dependent constraints.
- **03-cpp-pointer-trick:** A C++ manual memory management task involving pointer aliasing and custom cleanup logic.
